Cursor Learning Roadmap

Cursor 学习步骤（单页面）

用 7 个步骤快速建立实战能力：能提需求、能读代码、能改代码、能验证结果。每一步都聚焦“行动 + 产出”，不走空话路线。

7 核心学习步骤
30-60 分钟/次练习建议
分析→修改→验证 标准闭环工作流
1

熟悉界面与基础操作

  • 认识 Chat、Composer、Terminal 面板，知道各自职责。
  • 掌握常用快捷键：定位文件、查找符号、查看变更。
  • 在小项目练习，先建立“可控感”再进阶。
2

学会提“可执行”的需求

  • 需求模板：背景 + 目标 + 范围 + 约束 + 验收标准。
  • 例如：新增登录页，复用现有 API，不改数据库结构。
  • 结论先行、约束明确，AI 输出更稳定。
3

先探索上下文，再实施修改

  • 先让 AI 说明项目结构、入口文件、关键依赖。
  • 确认理解一致后再开始改代码，减少返工。
  • 小步快跑：一次只做一个可验证目标。
4

按任务拆解迭代推进

  • 拆分为：页面结构、样式系统、功能逻辑、测试验证。
  • 每轮都要求输出“改动点 + 风险点 + 回滚思路”。
  • 复杂需求先出计划，再按计划执行。
5

强制执行验证流程

  • 改动后必须跑测试、构建、静态检查（lint/type check）。
  • 失败时让 AI 解释根因，不只给表面修补。
  • 形成“先验证，再提交”的工程纪律。
6

沉淀高复用 Prompt 模板

  • 把高质量提问沉淀成模板，复用到下一次任务。
  • 保持输出格式一致（例如：变更列表、测试结果、风险点）。
  • 把模板放进 README 或团队文档，降低协作成本。
7

形成个人稳定工作流

  • 固定流程：分析需求 → 浏览代码 → 实施改动 → 自动验证 → 提交。
  • 关键变更写清 commit message，方便回溯与复盘。
  • 周期复盘：哪些提问方式最省时、最准确。
✓

学习总结

Cursor 的核心价值是“把正确流程放大”，而不是“替你省略思考”。当你能把模糊需求转成结构化指令，并坚持验证闭环，效率和质量会同时提升。建议你把这个页面作为个人学习看板，持续更新自己的实战经验。
